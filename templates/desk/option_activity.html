Review an option activity statement

Read a CSV export from IBKR to see reported assignments, exercises, expirations and related stock deliveries. The file stays on this computer. Importing evidence cannot change your positions, live P&L, trading controls or unresolved review holds.

Which file should I export?

In IBKR's Activity Flex Queries, export only the Options, Exercises, Assignments and Expirations section as a detailed CSV for the selected account. Include the real Account ID, not an alias. Use dates such as 2026-09-26.

Required columns: Account ID, Asset Class, Currency, Conid, Symbol, Date, Transaction Type, Quantity and Trade ID. Include Realized P/L, Comm/Tax, Trade Price, Proceeds, Basis and Underlying Symbol when available. Missing money amounts stay unknown.

Use a single section with a header row, up to 3,000 rows and 1 MB. Summary rows, model allocations, other instruments, zero-quantity/cancelled records and multi-section statements need separate review. The importer supports standard OPT/STK activity labels; an unrecognized format is rejected.
